# Jakarta AQI Streamlit Bonus

This bonus application demonstrates how the trained **Multiple Linear Regression** model can be deployed as an interactive decision-support tool for predicting Jakarta's Air Quality Index (AQI).

The application is directly connected to the modelling notebook used in the DDW project. Rather than using a separately trained model, it loads the exact model and cleaned dataset generated by the notebook.

---

---

# Workflow

The Streamlit application is integrated with the DDW modelling notebook.

When the notebook is executed, it automatically performs the following steps:

1. Cleans and preprocesses the Jakarta AQI dataset.
2. Exports the cleaned dataset as:
   - `jakarta_air_quality_cleaned.xlsx`
   - `jakarta_air_quality_cleaned.csv`
3. Trains the Multiple Linear Regression model.
4. Saves the trained model as:
   - `aqi_model.npz`
5. Places all generated files directly inside the **Bonus Template** folder.

The Streamlit application then loads these generated files directly, ensuring that all predictions are made using the **exact model and cleaned dataset produced by the notebook**.

This creates a complete end-to-end workflow:

```text
Raw Dataset
      │
      ▼
Project_Report_Template.ipynb
      │
      ├── Clean dataset (.xlsx)
      ├── Clean dataset (.csv)
      └── Trained model (.npz)
              │
              ▼
      Streamlit Bonus Application
              │
              ▼
AQI Prediction + Pollutant Contribution Analysis
```

---

# Features

The application allows users to:

- Enter pollutant concentrations (PM10, SO₂, CO, O₃ and NO₂).
- Predict Jakarta's Air Quality Index (AQI).
- Display the estimated AQI category.
- Identify the strongest statistical pollutant contribution.
- Visualise relative pollutant contributions.
- Provide possible emission-source investigation directions.
- Display public-health recommendations.
- Explain the model methodology and performance.
- Show dataset transparency and sample records.

---

# Run

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

Run the DDW notebook first.

The notebook will automatically generate:

- `aqi_model.npz`
- `jakarta_air_quality_cleaned.xlsx`
- `jakarta_air_quality_cleaned.csv`

inside the **Bonus Template** folder.

Then launch the Streamlit application:

```bash
streamlit run Home.py
```

---

# Notes

- The application uses the exact trained model generated by the notebook.
- No manual copying of files is required after running the notebook.
- Pollutant contributions represent the model's statistical interpretation and should not be treated as proof of causation.
- Possible emission sources are intended to guide further investigation and should be validated using geographical, meteorological and emissions data.
